# ぱくっと！ゴブとも

スマホのブラウザで遊べる、コマを重ねられる三目並べゲームです。

## あそびかた
- 3×3の盤面で、縦・横・斜めに自分のコマを3個並べると勝ちです。
- コマは小・中・大の3種類で、各サイズ2個ずつあります。
- 大きなコマは小さなコマにかぶせられます。
- 盤面にある自分のコマを別のマスに動かすこともできます。
- CPU対戦・2人対戦、先手・後手、青とオレンジ／白と黒の配色に対応しています。

## GitHub Pages
このリポジトリは静的なサイトです。Settings → Pages で以下を設定すると公開できます。

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/(root)`

公開先: https://reki2000.github.io/gobutomo/

`index.html` がゲーム本体です。
